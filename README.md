# HyperOS A5 Launcher — v0.2.0

Launcher comunitario para Android, inspirado en el estilo visual de Xiaomi HyperOS 2 y HyperOS 3. No es software oficial de Xiaomi ni una ROM completa.

## Novedades de la versión 0.2.0
- Tienda local de temas con cuatro presets: HyperOS 2 Claro/Oscuro y HyperOS 3 Claro/Oscuro.
- Guardado del tema elegido.
- Importar fondo de pantalla desde el selector de archivos de Android.
- Importar una imagen como icono personalizado para una aplicación concreta.
- Cambiar el icono de una aplicación manteniéndola pulsada.
- Búsqueda de aplicaciones y apertura de información de la app.

## Abrir el proyecto
1. Descomprime el ZIP.
2. Abre la carpeta `HyperOS-Redmi-A5` en Android Studio.
3. Sincroniza Gradle y ejecuta en un dispositivo Android.
4. Selecciona HyperOS A5 Launcher como aplicación de inicio predeterminada si quieres usarlo como launcher.

## Limitaciones
- Los temas cambian la paleta del launcher, no toda la interfaz del sistema Android.
- Los iconos personalizados se aplican dentro de este launcher; no alteran el icono de la app en el sistema.
- La tienda de esta versión es local, con temas incluidos; aún no descarga temas de un servidor.
- El selector permite importar imágenes como iconos individuales. No se importan paquetes de iconos de terceros automáticamente.
- Proyecto comunitario no afiliado a Xiaomi. Las marcas y nombres pertenecen a sus propietarios.
